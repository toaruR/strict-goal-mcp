# /goal: strict-goal 連携ゴール完遂コマンド

ユーザーが `/goal <目標>` を実行した際、エージェントのプロンプト自己完結や途中のサボりを防ぐため、**`strict-goal` ハーネスを自動起動して客観的な検証・合否判定のもとでゴールを達成します。**

---

## 実行手順

1. **目標の読み込み**:
   - `/goal` に続く指示文を抽出し、目標とする成果物を特定する。

2. **strict-goal スキルの起動**:
   - `strict-goal` スキルを適用し、`design` → `plan` → `implement`（または適切な連鎖）を開始する。
   - 開始バナーを出力してユーザーにパイプラインを明示する。

3. **自律ループの完遂**:
   - 各フェーズ（仕様策定・タスク分解・実装）について、サーバー判定が `FINAL` になるまで自律的に周回する。
   - 特にコンテキスト消費の激しい `implement` フェーズは、親エージェントのコンテキスト保護のためサブエージェント（`coder` / `self`）へ委譲して実行することを推奨。
   - 単に「コードを書いた」だけでなく、全テストのパス（終了コード 0）と客観的エビデンスを添付する。
   - `node strict-goal/server/helper.js fileset ...` や `test-run ...` を活用して正確にコミット・採点を行う。

4. **完了報告**:
   - 全フェーズが `FINAL` に達したら、成果物・テスト結果・監査ログを提示して終了する。
